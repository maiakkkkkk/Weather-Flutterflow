# 🌦️ Weather App — Projeto Integrador / Integrative Project

Aplicativo móvel desenvolvido em **Flutter** e **FlutterFlow**, com o objetivo de exibir informações meteorológicas em tempo real.  
Desenvolvido como parte do **Projeto Integrador** do curso de **Análise e Desenvolvimento de Sistemas**.

## 📱 Sobre o Projeto / About the Project

🇧🇷 **Descrição:**  
O *Weather App* fornece dados de clima, temperatura e condições atmosféricas atualizadas, com uma interface moderna e intuitiva.  
Ele foi desenvolvido para demonstrar o uso de **APIs REST**, **gerenciamento de estado** e **boas práticas de design mobile**.

🇺🇸 **Description:**  
*Weather App* provides real-time weather, temperature, and atmospheric data through a modern and user-friendly interface.  
It was built to demonstrate the use of **REST APIs**, **state management**, and **mobile design best practices**.

---

### 🌐 **Executar no navegador / Run on Web Browser**

Primeiro, inicie o `chromedriver`:

```bash
chromedriver --port=4444
```

Em seguida, execute:

```bash
flutter drive \
  --driver=test_driver/integration_test.dart \
  --target=integration_test/test.dart \
  -d chrome
```
